# homebrew-mycota

The Homebrew tap for Mycophonic's command-line tools. Every formula builds from
its project's `main` branch, so each install needs `--head`.

```bash
brew tap mycophonic/mycota
brew install --head mycophonic/mycota/haustorium
brew install --head mycophonic/mycota/saprobe
brew install --head mycophonic/mycota/sporeprint
```

| Formula | Tool |
|---|---|
| [haustorium](https://github.com/mycophonic/haustorium) | Audio quality analysis for music defect detection |
| [saprobe](https://github.com/mycophonic/saprobe) | Audio decoding |
| [sporeprint](https://github.com/mycophonic/sporeprint) | Audio fingerprinting with Chromaprint |
